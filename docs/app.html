Create an iOS Shortcut (no browser needed)

This lets you rewrite clipboard text with zero browser interaction.
Flow: Copy text → Run shortcut → Paste result.
  1. Open the Shortcuts app on your iPhone
  2. Tap + to create a new shortcut
  3. Add action: Get Clipboard
  4. Add action: Get Contents of URL
    URL: https://api.openai.com/v1/chat/completions
    Method: POST
    Headers: add two:
      Content-Type = application/json
      Authorization = Bearer YOUR_API_KEY
    Request Body: JSON with these keys:
      model → Text → gpt-4o-mini
      messages → Array → add 2 Dictionary items:
        1. role: system, content: Rewrite the following text to be clearer and more polished. Return ONLY the rewritten text.
        2. role: user, content: select Clipboard variable
  5. Add action: Get Dictionary Value
    Key path: choices.1.message.content
  6. Add action: Copy to Clipboard
  7. Add action: Show Notification → "Rewritten & copied!"
  8. Add to Home Screen from the shortcut's settings
Pro tip: On iPhone, go to Settings → Accessibility → Touch → Back Tap → assign this shortcut to Double or Triple tap. Then you can rewrite by tapping the back of your phone!
